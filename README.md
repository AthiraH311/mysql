## 🗄️ MySQL Employee Database — DDL & Constraints

This project is a **MySQL Employee Database** created as part of *Assignment 1 – DDL Commands & Constraints*. It includes three main tables: **Departments, Location, and Employees**, and demonstrates the use of essential DDL commands such as `CREATE`, `ALTER`, `RENAME`, `TRUNCATE`, and `DROP`.

The project also focuses on maintaining **data integrity using SQL constraints**. It implements `PRIMARY KEY`, `FOREIGN KEY`, `NOT NULL`, `UNIQUE`, `CHECK`, `DEFAULT`, `ENUM`, and `AUTO_INCREMENT` constraints to ensure valid and consistent data across the database.

Overall, this assignment provides practical experience in **creating, modifying, managing, and maintaining relational database structures using MySQL**.
